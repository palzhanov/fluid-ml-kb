# Latent Dynamics Networks (LDNets)

status: first-pass
family: latent dynamics
key papers: [regazzoni2024ldnet]

## Core idea
Learn a low-dimensional latent state s(t) whose evolution is driven by time-dependent inputs u(t) (and parameters), and a decoder that maps the latent state plus a spatial query point x to the field value y(x, t). Crucially there is **no encoder**: the latent state is never obtained by compressing a high-dimensional snapshot. It is generated by integrating a learned ODE forward from a fixed initial latent state, and trained end-to-end so that the decoded fields match data.

## Architecture
- **Dynamics network** NN_dyn: (s(t), u(t)) → ds/dt. Integrated with an explicit scheme (forward Euler / RK) from s(0) = s₀ (fixed). ⚠ unverified: exact integrator used per test case.
- **Reconstruction network** NN_rec: (s(t), x) → y(x, t). Evaluated pointwise, so it is a neural field conditioned on the latent state.
- Both are plain fully connected networks; latent dimension is small (single digits in several tests ⚠ unverified).

## Training data and loss
Time series of input signals u(t) paired with outputs observed at (possibly sparse, possibly varying) space–time points. Loss is the misfit of NN_rec at the observed points, plus regularization. Training requires backpropagating through the time integration (like a neural ODE trained by discretize-then-optimize).

## Mesh / geometry handling
Mesh-free in output: queries any x in the (fixed) domain, so training data need not live on a common mesh. Geometry is **fixed**; there is no mechanism for varying domain shape. ⚠ check whether any test varies geometry through inputs.

## Generalization
- Across parameters / inputs: designed for time-varying input signals, the main selling point versus parameter-to-solution ROMs.
- Across geometry: not addressed.
- In time: autoregressive latent integration; can run beyond training horizon in principle, but extrapolation quality is an empirical question.
- Across resolution: output is continuous in x, so evaluation resolution is free.

## Cost
Very cheap online: a small ODE in latent space plus decoder queries only where needed. Offline cost dominated by generating training simulations and by backprop-through-time.

## Benchmarks reported
Test cases include an advection–diffusion–reaction problem, cardiac electrophysiology (Aliev–Panfilov type), and an unsteady incompressible Navier–Stokes problem with time-dependent inputs ⚠ unverified exact configurations. Compared against POD-based and autoencoder-based ROMs with fewer trainable parameters reported for LDNet. TODO(numbers).

## Known failure modes / limitations
- No encoder: cannot directly ingest a new observed state (e.g., a varying initial condition or a measurement) without solving an inverse problem for s. Varying initial conditions must be represented through inputs/parameters. (our observation)
- Fixed geometry. (our observation)
- Training through long time integrations: possible gradient issues and cost; stiffness of learned dynamics not controlled. (our observation, general neural-ODE issue)
- No physics constraints and no error estimate. (our observation)

## Relation to other methods
- vs DL-ROM / POD-DL-ROM: those learn μ,t → state via a decoder from a latent obtained by regression; LDNet makes the latent evolve dynamically and is driven by inputs.
- vs LED, Koopman AE, LaSDI: those have encoders and learn latent dynamics from encoded snapshots; LDNet skips the encoder.
- vs DINo / CORAL: also neural-field decoders with latent dynamics; DINo is the closest ML-community analogue (latent ODE + INR). Worth a careful side-by-side.
- vs DeepONet: NN_rec(s, x) has the same "branch-like code + trunk-like query" structure, with s produced by a dynamical system instead of a branch net.

## Open questions
- Can an encoder or filter (e.g., EnKF in latent space) be bolted on for data assimilation without losing the benefits?
- How does it scale to turbulent / chaotic flows where a small deterministic latent state is insufficient?
- Geometry: condition NN_rec on a geometry code (as in neural-field operators) and test on families of domains.
- Can structure (stability, dissipativity, port-Hamiltonian form) be imposed on NN_dyn?
