# Neural-field operators: DINo, CORAL

status: first-pass
family: neural field
key papers: [yin2023dino], [serrano2023coral]

## Core idea
Represent each field by a code that modulates a shared implicit neural representation (INR) f(x; z). Learn dynamics/operators on the codes.
- **DINo** [yin2023dino]: auto-decoding (no encoder net; codes optimized per sample), latent ODE on codes, continuous in space and time.
- **CORAL** [serrano2023coral]: same INR-code idea, with meta-learning to obtain codes quickly; operator learned as a map between codes; handles general geometries and irregular sampling.

## Architecture
Modulated SIREN/Fourier-feature INR + latent processor (MLP or ODE).

## Training data and loss
Fields sampled at arbitrary points; reconstruction + latent prediction.

## Mesh / geometry handling
Mesh-free; arbitrary observation points; geometry variation in CORAL.

## Generalization
- Space: query anywhere.
- Time: DINo continuous-time extrapolation tested.
- Geometry: CORAL.

## Cost
Encoding new data requires inner-loop optimization (auto-decoding) unless meta-learned.

## Benchmarks reported
DINo: wave, Navier–Stokes, shallow water on sphere ⚠ unverified; CORAL: airfoil, NS, elasticity ⚠. TODO(numbers).

## Known failure modes / limitations
INR spectral bias for sharp features; code-fitting cost.

## Relation to other methods
**Closest ML-community analogue of LDNet.** LDNet = DINo without auto-decoding (latent generated by input-driven ODE from a fixed start). A careful comparison is missing in the literature as far as we know ⚠ check.
